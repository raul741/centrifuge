# centrifuge

Tool created for converting Factorio spritesheets into animated GIFs.

## Usage

```bash
git clone https://github.com/raul741/centrifuge
cd centrifuge
python3 -m venv .venv
source ./.venv/bin/activate
pip install -r requirements.txt
./centrifuge.py -i assembling-machine-3.png -o assembling-machine-3.gif
```
